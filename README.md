# Sistem-Manajemen-Data-pada-Album-Pop-Internasional
Mini Project_Muhammad Ihsan_009
A. Penjelasan Program Sistem Manajemen Data pada Album Pop Internasional.
Data Album Pop berisi Album, Artis, dan Rating Album.
Program berbentuk menu pilihan berulang (while True) dan Menggunakan conditional statement,
lalu data disimpan dalam bentuk list atau tuple ("Album", "Artis", "Rating berupa int/float").
Terdapat 5 Menu pilihan pada program ini, yaitu.
1. Lihat Daftar Album Pop
2. Tambahkan Album Favorit Anda!
3. Ubah Rating Album
4. Hapus Album
5. Keluar

Pada menu pilihan pertama, user menginput "1" untuk menampilkan seluruh isi album. 
Program menampilkan 5 Album terlebih dahulu beserta artis dan rating albumnya. 
setelah itu print daftar album pop menggunakan loop list agar terurut dalam bentuk yang rapi.

hingga kembali ke menu awal, user memilih pilihan kedua untuk menambahkan Album menggunakan while True, Conditional Statement. selain Album terdapat Artis dan Rating pada album. Jika user merasa cukup dengan albumnya, maka ketik "selesai". dan program continue ke menu awal.

kembali ke menu awal, user memilih pilihan ketiga untuk merating sebuah album yang sekiranya user dapat memberikan review melalui poin bernilai 0-10 (bisa dalam bentuk desimal, poin ini menggunakan float dalam program). 
Program akan print kembali album beserta ratingnya, jika user mengganti rating sebuah album, maka program akan print album beserta rating barunya dalam bentuk list yang rapi.

kembali lagi ke menu awal, user memilih pilihan keempat untuk menghapus sebuah album yang tidak diperlukan didalam list, user menginput album yang dimaksud, maka program akan mengeprint daftar album baru.

terakhir, jika user memilih pilihan terakhir yaitu keluar, maka program akan mengakhiri sistem tsb. program akan print "Terima kasih telah mendengarkan karya internasional!"
